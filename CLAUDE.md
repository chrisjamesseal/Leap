## UI work
- Before writing or changing any UI code, follow the Web Interface Guidelines:
  https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md
- Fetch them once per session and keep them in mind while building
- Cover accessibility, focus states, form behaviour, touch targets and motion
- Do a quick check against them before calling a UI task finished

## How to work with me
- I'm the designer giving feedback, so assume I can't do the dev work
- Do all dev work yourself, including merging, and never ask me to run commands
- Finish with a live link to the app or page
- Push straight to the default branch in small commits unless I say otherwise

## Writing style
- No long dashes
- Write like a human, not an AI
- Prefer bullet points over big blocks of text

## Mobile first
- Check layouts at phone width first, I often use these from my phone

## Saving tokens
- Search files before reading them whole
- Keep replies short and to the point

## Project layout

- `index.html` is the main page
